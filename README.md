# POE2 Campaign Guide

Complete Path of Exile 2 campaign walkthrough with all permanent rewards, skill points, and optimal pathing for Acts 1–4, the Interludes (Acts 5.1–5.3), and Endgame.

**Live site:** [domistae.github.io/poe2-leveling](https://domistae.github.io/poe2-leveling/)
**Target patch:** PoE 2 patch 0.5 (Return of the Ancients)

## Features

- ✓ **Checkbox Progress Tracking** — Click to mark steps complete
- 💾 **Auto-Save** — Progress saves to browser localStorage
- 📤 **Export/Import** — Transfer progress between devices with shareable codes
- 🎯 **Permanent Rewards** — All skill points, spirit bonuses, and unlocks highlighted
- ⚡ **Optimal Pathing** — Efficient waypoint routing to minimize backtracking
- 🌓 **Light & Dark Themes** — Respects your OS preference, defaults to dark
- 📱 **Mobile-Friendly** — Responsive sidebar layout

## AI-assisted, community-verified

This guide was produced with AI assistance and manually verified against the current patch. Game mechanics, skill point locations, and reward placements were cross-checked against in-game testing and patch notes, with particular attention to patch 0.5 (Return of the Ancients) changes — including the new endgame storylines (Fortress, Delirium, Breach/Genesis Tree, Ritual, Expedition) and Act 4 reward shifts.

If you spot inaccuracies or have suggestions, please open an issue.
